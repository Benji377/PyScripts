# 💬 GitHub Discussions for PyScripts

Welcome to the PyScripts Discussion Board!

This is the place for:
- 💡 Sharing ideas for new scripts
- 🤔 Asking how a script works or how to tweak it
- 🛠 Getting help with dependencies or Python-related questions
- 🎉 Showing off something cool you made using a script from this repo
- 🧠 Learning from each other and improving scripts together

We use Discussions instead of Issues for general conversation and community support — because this repo is more of a casual toolbox than a tightly maintained package.

---

### 🧵 Start Here

We’ve pinned a **Welcome Thread** — feel free to introduce yourself and share how you’re using PyScripts!

If you have a new idea, question, or improvement suggestion — start a new discussion under the appropriate category.

Let’s keep it kind, curious, and collaborative. 🚀

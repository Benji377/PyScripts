# 🛠 Utility Scripts

This is a grab bag of small but handy tools — scripts you might reach for when you need to generate a password or shorten a URL in a hurry.

### 📝 Scripts

- **`password_generator.py`**  
  Quickly generates a random string of characters with a length you specify. Super useful for quick, secure password creation.

- **`url_shortener.py`**  
  Shortens a long URL using the `pyshorteners` package — simple and clean.

---
No heavy setup required — each file is ready to run on its own.

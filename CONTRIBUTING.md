# 🤝 Contributing to PyScripts

Hey! 👋  
Thanks for considering contributing to **PyScripts** — I really appreciate it.

This project is a personal collection of random but (hopefully) useful Python scripts. Contributions are welcome as long as they follow the style and structure of the repo. Here's how you can help:

---

## 🧑‍💻 What You Can Contribute

- 📁 New scripts (see folder structure below)
- 🧼 Refactor or clean up existing code
- 📚 Improve documentation or add usage examples
- 🪲 Fix bugs or improve performance
- 🆕 Suggest ideas or new folder categories

---

## 📁 Folder Structure

- `automation/` – Scripts that automate tasks (e.g., bots, file renamers)
- `data_processing/` – Scripts that handle, clean, or generate data
- `utils/` – Small, general-purpose tools (e.g., password generators)
- `experiments/` – Prototypes, tools, or fun ideas in testing

Each folder contains a `README.md` and standalone Python scripts.

---

## 📝 Script Requirements

When adding a script:

1. **Use the standard header comment** (see template below).
2. **Keep it self-contained** (no cross-script imports unless justified).
3. **List any third-party packages** at the top as a comment.
4. **Put it in the right folder** and update the folder's `README.md`.

---

## 🧾 Script Header Template

Please use this comment block at the top of your script:

```python
"""
Title: <Script Title>
Description: <Brief explanation of what the script does.>
Author: <Your name or GitHub handle>
Created: <Date>
Last Updated: <Optional>

Usage:
    python <script_name>.py

Dependencies:
    - <package1>
    - <package2>
    (Install with: pip install <package1> <package2>)

Notes:
    - Any extra instructions, warnings, or info.
"""
```

---

## 🔀 Submitting a Pull Request

1. Fork the repo
2. Create a new branch (`git checkout -b feature/script-name`)
3. Commit your changes
4. Push to your fork
5. Open a pull request with a clear description

---

## 🙌 Thanks Again!

This project is a bit chaotic by design — but let’s keep it fun, helpful, and easy to use. Happy scripting!
